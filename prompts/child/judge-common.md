# 判断委譲の子の共通ルール

あなたは起動時にリポジトリの CLAUDE.md を読んでいません。判断・トリアージ・調査に要る規則はここにあります。

- 処理対象かは担当者だけで決まります。人間へ渡すときは理由をコメントに書いてから担当者を変えます。仕様の確認を求めるなら `Question` へ動かし、詰まって渡すならステータスを動かしません
- 判断が何も残っていないイシューは `Duplicate` か `Canceled` で閉じてよく、`Done` へは動かしません。条件と書き方は `{{promptDir}}/child/impl-from-triage.md`「閉じてよいのは、判断が何も残っていないときだけ」です
- 通知は人間が何かをする必要があるときだけ送ります
- 説明文の先頭ブロックは `npx tsx {{coreDir}}/src/cli/personal-field.ts` で書き、本文に HTML コメントを書きません
